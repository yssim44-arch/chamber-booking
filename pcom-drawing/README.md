# pCOM Drawing 8BIT · Windows

사용자가 제공한 기본사양과 18개 원본 도면을 바탕으로 만든 8비트 케이블 도면 작성 프로그램입니다.

## Windows에서 사용

1. `pCOM-8bit-Windows-x64.zip`을 풀고 `pCOM-8bit.exe`를 실행합니다.
2. Edge가 있으면 주소창 없는 전용 창으로 열립니다. Edge를 찾지 못하면 기본 브라우저로 열립니다. Windows 10/11 64비트용이며 Python·Node·Go를 설치할 필요가 없습니다.
3. 기본 예시 또는 기존 도면 프리셋을 선택하고 사양을 수정합니다.
4. 연결도와 핀표를 확인한 뒤 **PPTX 도면 저장**을 누릅니다. 다운로드 폴더는 브라우저의 저장 설정을 따릅니다.
5. **사양 저장(JSON)**으로 작업을 보관하고, 나중에 **사양 불러오기**로 복원할 수 있습니다.
6. 우측 상단 **종료**로 프로그램을 닫습니다. 창만 닫았을 때도 약 3분 뒤 로컬 프로그램이 자동 종료됩니다.

화면과 프리셋은 실행파일에 포함됩니다. 인터넷이나 서버 계정은 필요하지 않습니다. 실행 중에는 자기 컴퓨터의 `127.0.0.1:8752`에서만 동작하며 외부 컴퓨터에는 공개하지 않습니다. 같은 주소에서 마지막 사양을 기기에 저장하고 복원합니다. 이동·백업에는 JSON 저장을 사용하세요.

## 이 버전에서 가능한 작업

- 8비트(A8), MASTER/SLAVE, USER RS-232/RS-485, 3A/6A 선택.
- 확인된 I/O 유형 `0 / 1 / 2 / F / L` 및 기존 자료의 통신·전원 커넥터 선택.
- 본체 15/12/5핀과 상대측 핀 대응 생성. A Type·B Type·26핀 통합 배선 구분.
- BOARD 전원 핀 순서를 별도 선택. SYNUS/LW SLAVE 프리셋의 역순 배선 보존.
- 네 코드 길이 및 BELT/BOARD 추가 치수 입력, 10mm 단위 검사.
- 기존 PPT 18장과 기본 예시 등 19개 프리셋. 동명 SU 두 개정 구분.
- 도면번호 생성·해석. 기존 코드가 일치하면 핀 극성·색상·보조 치수도 프리셋에서 복원.
- 편집 가능한 PPTX: 연결 개략도, 핀표, 주요 자재표, 출처·검토 항목.
- SVG 도면 및 JSON 사양 저장/불러오기.

PPTX의 선·도형·문자는 PowerPoint에서 각각 편집할 수 있습니다. 첫 시트는 연결 개략도이고 다음 시트에 핀표·주요 자재표·참고 사항이 이어집니다.

## 도면 해석 범위

이 버전은 **개략 연결도 생성기**입니다. 원본 PPT의 커넥터 기구 그림·전체 제조 BOM·공차·라벨 작업 지시를 그대로 재현하지 않습니다. 주요 자재표에는 단자·튜브·스토퍼 전체 산출이 포함되지 않습니다. 원문 충돌과 미확정 품번은 화면과 PPTX의 검토 항목에 남습니다.

- 코드 `0`은 커넥터 없음입니다. 선재 길이가 있으면 개방단을 표시하고 검사·제거용 커넥터는 완성품에 포함하지 않습니다.
- `51103-0310`(기본사양)과 `51103-0300`(일부 BOM), HIF/HIF6 표기 차이는 자동으로 없애지 않습니다.
- 원본 `08`은 A8로 생성하며 출처에 기존 도면번호를 보존합니다.
- 900mm 초과 길이는 기존 장척 도면 사례를 위한 확장 입력으로 표시합니다.
- 코드만으로 알 수 없는 핀 극성·추가 치수는 직접 확인하거나 기존 도면 프리셋을 사용합니다.
- 16비트는 지원하지 않습니다. 전체 코드표 중 배선이 확인되지 않은 커넥터 유형은 선택지에서 제외했습니다.

## 개발·검증

Go 1.26 이상이 필요하며 외부 Go 모듈 의존성은 없습니다.

```sh
go test ./...
go run . --headless --addr 127.0.0.1:8000
```

Windows 빌드:

```sh
CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build -buildvcs=false -trimpath -ldflags='-s -w -H=windowsgui' -o dist/pCOM-8bit.exe .
```

Windows PowerShell에서는 `build.ps1`을 사용할 수 있습니다. GUI 배포에서 사용하는 기본 포트는 8752이며 `--addr 127.0.0.1:<port>`로 바꿀 수 있습니다. `--headless`는 창과 자동 종료 없이 개발 서버로 실행하는 옵션입니다.

핵심 소스: `domain.go`(사양·코드·핀), `drawing.go`(SVG/PPTX), `main.go`(로컬 실행), `static/`(화면), `data/presets.json`(출처별 사양).

검증 범위: Go 단위/통합 테스트, Chromium 화면과 다운로드 흐름, 생성 PPTX의 XML/PowerPoint 구조 및 LibreOffice 렌더. Windows 실행파일은 크로스 컴파일 산출물이며 이 Linux 환경에서 Windows GUI를 직접 실행한 것은 아닙니다.
