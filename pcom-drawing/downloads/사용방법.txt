pCOM Drawing 8BIT · Windows v1.0.0

1. 압축을 풀고 pCOM-8bit.exe를 실행하세요.
2. Edge 전용 창 또는 기본 브라우저가 열립니다. 별도 개발 도구 설치나 인터넷 연결은 필요하지 않습니다.
3. 기본 예시/기존 도면을 선택하고 사양을 수정한 뒤 PPTX 도면 내보내기를 누르세요.
4. 설정 저장(JSON)과 설정 불러오기로 작업을 보관·복원하세요.
5. 종료 버튼으로 프로그램을 끝내세요. 창만 닫아도 약 3분 뒤 자동 종료됩니다.

Windows 10/11 64비트용입니다. 실행 중 자기 컴퓨터의 127.0.0.1:8752에서만 동작합니다.
PPTX는 선·도형·문자를 편집할 수 있는 개략 연결도 + 핀표 + 주요 자재표 + 검토 항목입니다.
원본 커넥터 기구 형상이나 전체 제작 BOM을 그대로 복제하는 버전은 아닙니다.
기존 자료의 불일치와 미확정 품번은 화면·PPTX에 표시됩니다. 16비트는 지원하지 않습니다.

검증: 19개 프리셋의 PPTX/XML/배선, Chromium 화면, LibreOffice 렌더 통과.
Windows 실행파일은 크로스 컴파일로 생성했으며 Windows GUI 직접 실행 검증은 아직 하지 않았습니다.
